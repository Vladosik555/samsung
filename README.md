# Multilayer Perceptron from scratch (MLP)

Реализация полносвязной нейронной сети (многослойного персептрона) «с нуля» с использованием библиотеки NumPy для решения задачи бинарной классификации (диагностика опухолей молочной железы на базе набора данных Breast Cancer Wisconsin Diagnostic).

Проект выполнен без использования высокоуровневых библиотек машинного обучения (PyTorch, TensorFlow, Keras, scikit-learn). Прямой и обратный проход (Backpropagation), алгоритм оптимизации (Mini-batch SGD) и масштабирование данных реализованы вручную.

---

## 📁 Структура проекта

* `spliter.py` — предобработка исходных данных, масштабирование (MinMaxScaler) и разделение на обучающую и валидационную выборки.
* `train.py` — модуль конфигурирования и обучения сети с выводом графиков кривых обучения и сохранением весов.
* `predict.py` — модуль инференса (предсказания) и финальной валидации по функции потерь Binary Cross-Entropy.
* `saved_model.npy` — файл с сериализованной архитектурой и обученными весами модели.
* `eda.ipynb` — ноутбук с разведочным анализом данных (матрица корреляций, фактор инфляции дисперсии VIF).
* `mlp_otchet.pdf` — академический отчет по проекту с математическими выкладками, формулами и рассуждениями.
* `data.csv` (или `mlp_data.csv`) — исходный датасет.
